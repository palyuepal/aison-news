# NutriFact Lab — MVP v0.3

Traditional Chinese nutrition + supplement evidence-learning site for Hong Kong readers.

**Tagline:** 營養，唔好靠估。

## Pages
- `/` homepage
- `/supplements` searchable ingredient library
- `/supplements/[slug]` indexable ingredient pages
- `/evidence` evidence methodology
- `/editorial-policy` publishing rules
- `/about` product scope
- `/disclaimer` safety / medical-information disclaimer

## Seed ingredients
Magnesium, Vitamin D, Omega-3, Creatine, Probiotics, Iron, Zinc, Vitamin B12.

Evidence labels are editorial summaries, not formal GRADE assessments or clinical guidelines.
